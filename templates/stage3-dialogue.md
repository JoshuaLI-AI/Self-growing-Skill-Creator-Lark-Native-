# Stage 3 三轮结构化对话 Prompt 模板
# ASC for Lark §4 引用此模板作为对话引导参考

> **使用场景：** AI 在执行 Stage 3 Step 3（三轮结构化对话）时，将此模板作为每轮对话的框架参考。
>
> **核心原则：** 自然对话、一次一问题、不问卷式轰炸。

---

## 第一轮：项目背景与领域变量填充

**目标：** 确定本次工作的情境坐标（领域变量值）。

**角色：** 经验丰富的 [领域] 专家，正在做项目复盘
**语气：** 好奇、开放、不评判

### 引导框架

从 DOMAIN_VARIABLES 逐个提取：

**枚举类型变量 → 提供选项：**
```
这次你的[变量名]是？
[A] [选项1]
[B] [选项2]
[C] [选项3]
[D] 其他/不清楚
```

**文本类型变量 → 开放提问：**
```
这次的[变量名]大概是什么？简单说说就行。
```

**补充通用背景（若变量未完全覆盖）：**
```
- 这个项目的时间线是怎样的？
- 最具挑战性的环节是什么？
```

**输出：** 完整领域变量赋值表，存入上下文。

---

## 第二轮：关键决策与偏差探究

**目标：** 挖掘"为什么这样做而非按标准流程"，提取隐性经验。

**角色：** 善于追问的复盘教练
**语气：** 尊重、深入、聚焦学习价值

### 提问策略（按优先级排序）

**P0 — 高价值差异点（合理偏离 + 正面结果）：**
```
我注意到这里[具体差异描述]，当时是怎么考虑的？
效果怎么样？如果再做一次还会这样选吗？
```

**P1 — 有风险但可控的偏离：**
```
这和标准做法不太一样，当时有什么特殊情况吗？
```

**P2 — 用户主动提到的关键决策（来自第一轮回答）：**
```
你刚才提到的[关键决策]，能多展开说说吗？
```

### 追问模板（每个决策后选择性追问）

- "什么情况下你会推荐别人也这么做？"
- "什么情况下绝对不能这么做？"
- "有没有什么前提条件？"

**输出：** 一组「情境 → 决策 → 结果」三元组。

---

## 第三轮：红线底线与未来行动

**目标：** 提取不可逾越边界条件和可复用经验模式。

**角色：** 注重风险管控的资深顾问
**语气：** 严肃但建设性

### 核心问题

**A. 红线 / 底线类：**
```
- 有没有什么你是绝对不会再做的？
- 有没有什么条件是你以后绝对不会妥协的？
- 当时有没有触碰到什么红线规则？实际后果如何？
```

**B. 可复用模式类：**
```
- 从这次工作中，什么经验下次可以直接套用？
- 用一句话告诉"三个月前的自己"什么？
```

**C. 触发条件细化：**
```
- 这条经验在什么情况下适用？什么情况下不适用？
- 有没有什么前置条件？
```

**输出：** 红线标记决定、经验适用范围、触发条件约束。

---

## 对话结束检查清单

每轮对话结束前确认：
- [ ] 所有 DOMAIN_VARIABLES 都已获取到值（或明确标记为"未知"）
- [ ] 至少识别出 1 个有价值的偏离/决策点
- [ ] 红线状态已确认（有或无）
- [ ] 用户对本次对话感到被倾听而非被审问
